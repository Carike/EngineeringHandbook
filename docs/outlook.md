# Outlook

## Custom Holiday file

[Create a Custom Holiday File](https://www.slipstick.com/outlook/calendar/outlooks-holiday-file/#:~:text=%7C%20More%20Information-,Create%20a%20Custom%20Holiday%20File,-Because%20of%20tighter)

Things to note:
* Can only be full day events, no time
* Not sync'd, once off

Notes on special characters:
- Can use `:`, `()` 
- Cannot use (would need to confirm if it breaks) \ ` 
- Use `,` just between event and date

Example file (`2` is the number of events in the file)

```
[name of Holidays/Events] 2
Holiday description, yyyy/mm/dd
Holiday description, yyyy/mm/dd
```
